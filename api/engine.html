    TemplateEngine & SQLTemplate¶

    TemplateEngine ¶

    TemplateEngine(
    *,
    param_style: ParamStyle = ParamStyle.FORMAT,
    identifier_allowlist: set[str] | None = None,
    identifier_pattern: str
    | Pattern[str] = DEFAULT_IDENTIFIER_PATTERN,
    order_by_allowlist: set[str] | None = None,
    allow_multistatement: bool = False,
    empty_in_behavior: str = "error",
    search_path: list[str] | None = None,
    max_template_size: int
    | None = DEFAULT_MAX_TEMPLATE_SIZE,
    cache_size: int = 400,
    cache_dir: str | None = None,
)

    Main entry point for sql-template.

    Compiles Jinja2 SQL templates and renders them with automatic parameter binding, producing :class:QueryResult objects ready to pass to any PEP-249 or asyncpg database driver.

    Thread-safe. Create one instance at application startup and share it across threads. Each render call uses thread-local storage for parameter collection.

    Example::

    engine = TemplateEngine(param_style=ParamStyle.NAMED)
result = engine.prepare(
    "SELECT * FROM users WHERE id = {{ user_id }}",
    {"user_id": 42},
)
cursor.execute(result.sql, result.params)

    Create a new :class:TemplateEngine.

    		 FORMAT

    		 None

    Regex that every identifier must match. Defaults to ^[a-zA-Z_][a-zA-Z0-9_.]*$.

    		 DEFAULT_IDENTIFIER_PATTERN
    order_by_allowlist set[str] | None

    Optional separate allowlist for |orderby column names. Falls back to identifier_allowlist if None and an allowlist is needed.

    		 None
    allow_multistatement bool

    If False (default), a semicolon in the rendered SQL raises :exc:MultiStatementError.

    		 False
    empty_in_behavior str

    What to do when |inclause receives an empty collection. "error" (default) raises :exc:EmptyInClauseError; "false_condition" emits (1=0).

    		 'error'
    search_path list[str] | None

    Directories to search when loading template files via :meth:from_file. Required for {% extends %} and {% include %} directives.

    		 None
    max_template_size int | None

    Maximum allowed size of a template string in bytes. Defaults to 65 536 (64 KB). Set to None to disable the limit.

    		 DEFAULT_MAX_TEMPLATE_SIZE
    cache_size int

    Number of compiled templates to keep in the in-memory LRU cache. Set to 0 to disable in-memory caching. Defaults to 400.

    		 400
    cache_dir str | None

    Directory for Jinja2 bytecode cache (persists across process restarts). None (default) disables bytecode caching.

    		 None

    from_file ¶

    The file is resolved against the directories in search_path (set in the constructor). Template inheritance ({% extends %}) and includes ({% include %}) are also resolved from search_path.

    prepare ¶

    prepare(
    template: str, params: dict[str, Any]

    SQLTemplate ¶

    SQLTemplate(jinja_template: Any, engine: TemplateEngine)

    A compiled SQL template ready for rendering.

    Obtain instances via :meth:TemplateEngine.from_string or :meth:TemplateEngine.from_file. Instances are safe to call from multiple threads simultaneously (state lives in thread-local storage).
